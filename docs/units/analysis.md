# analysis: Read-only facts about the repo's files\: path-to-unit routing, anchor resolution and source windows, unit fingerprints and review stamps (check, stamp), and simplified\: debt scanning.

## Overview

The analysis unit holds the read-only facts stewards derives from the repo's files. It answers which unit owns a path, whether a unit's anchors still point at real definitions (tree-sitter: static grammars plus runtime ones from the user's stewards home), which lines an anchored interface spans, whether a unit's files changed since the last review, and where `simplified:` debt sits. It never edits source: the one thing it writes is the review stamp on a unit's card. A reader meets it through `stewards route`, `stewards check` and `stewards debt`, and through the source windows and ownership answers briefs are built from.

## How it works

Routing (src/route.rs): `owner` picks the unit whose glob matches most specifically (longest literal prefix, then fewest wildcards, ties by units.toml order) after normalizing ./ and backslashes; .stewards, the docs path and any .git component have no owner. `Router::overlaps` lists files two or more units match equally. Anchors (src/anchors.rs): `resolve` is DeadPath for absolute, ./.. , symlinked or unreadable paths. For the static grammar entries (rs py ts tsx js go sh c cpp cs hcl yaml) it parses with tree-sitter and runs the tags query plus the supplement in src/anchors/*.scm: Found is the line of a definition's name, never a mention; else DeadName. `A::b` is `b` inside `A`. Other extensions keep the first whole-word match. `source_window` returns (start line, text): the span cut to before+after+1 lines then `… (n more lines)`, or the match line plus context; None when dead. `interface_lines` gives the sorted span lines; java kt rb php swift scala keep the text block rule. Runtime grammars (src/anchors/runtime.rs): `&lt;stewards home>/grammars/&lt;lang>/` with lib.so (lib.dylib on macOS), tags.scm and optional `extensions` is loaded with libloading (RTLD_NOW) the first time its extension is looked up, only when the home is an absolute path; a static extension is never overridden. A grammar that cannot load (missing file, no symbol, null language, ABI outside the build's range, tags.scm not compiling) falls back to the text rule and `check` warns grammar_unusable. Check (src/check.rs): `fingerprint` hashes the sorted `path blob` lines a unit owns in the snapshot; `stamp` writes [reviewed]; `check_at` fails on unreviewed, stale, dead_anchor, unknown_interface and warns uncovered_interface, overlap, unowned, instructions_unlinked, grammar_unusable; a unit filter drops overlap, unowned, instructions_unlinked and grammar_unusable. src/debt.rs `scan` lists `simplified:` lines.

## How to change it

Start from the contract row for the function you touch (route-owner, route-overlaps, route-command, anchor-resolve, anchor-source-window, anchor-interface-lines, check-fingerprint, check-stamp, check-report, check-instructions, debt-scan) and its tests: tests/route*.rs, tests/anchors.rs, tests/check.rs, tests/debt.rs. Keep ownership consistent: fingerprint, overlap and debt keys rely on `owner`. Keep the fingerprint over owned files in the snapshot. Keep `resolve` and `source_window` safe on bad input: a dead anchor, never a panic or a read outside the repo. To support a static language add a `grammar(...)` entry in GRAMMARS with its TAGS_QUERY and, for omitted definitions, a supplement in src/anchors/. Runtime grammars run native code from the stewards home: never read them from a repo, keep the absolute-home rule, RTLD_NOW and the null check. Changing which findings fail or warn means updating check-report and the exit code together; uncovered_interface stays one finding per unit. Keep the stamp merge in `reviewed_at`.
