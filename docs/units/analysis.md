# analysis: Read-only facts about the repo's files\: path-to-unit routing, anchor resolution and source windows, unit fingerprints and review stamps (check, stamp), and simplified\: debt scanning.

## Overview

The analysis unit holds the read-only facts stewards derives from the repo's files. It answers which unit owns a path, whether a unit's anchors still point at real definitions (tree-sitter for the static grammars), which lines an anchored interface spans, whether a unit's files have changed since its last review, and where `simplified:` debt comments sit. It never edits source: the one thing it writes is the review stamp on a unit's card. A reader meets it through `stewards route`, `stewards check` and `stewards debt`, and through the source windows and ownership answers that briefs are built from.

## How it works

Routing lives in src/route.rs. `owner` picks the unit whose glob matches most specifically (longest literal prefix, then fewest wildcards, ties by units.toml order), after normalizing ./ and backslashes; .stewards, the docs path and any .git component (any ASCII case) have no owner. `Router::overlaps` lists files two or more units match at equal top specificity. `stewards route` maps each path to its unit (repo-prefixed in a workspace) or null. src/anchors.rs: `resolve` is DeadPath for absolute, ./.. , symlinked or unreadable paths For the twelve static grammar entries (rs py ts tsx js go sh c cpp cs hcl yaml) it parses with tree-sitter and runs the grammar's tags query plus the repo supplement in src/anchors/*.scm: Found is the line of a definition's name, never a mere mention; otherwise DeadName. `A::b` is `b` inside `A`; an HCL block is named by its labels. Other extensions keep the first whole-word match. `source_window` returns (start line, text): the definition span (with its doc comments, attributes, export or decorator) cut to before+after+1 lines then `… (n more lines)`, or the matched line plus context for text files; None when dead. `interface_lines(path, text, name)` gives the sorted lines of those spans; java kt rb php swift scala keep the text block rule, other files give none. src/next.rs uses it to tell whether a hunk touches an interface. src/check.rs: `fingerprint` hashes the sorted `path blob` lines of the files a unit owns in the snapshot into `sha256:&lt;hex>`; stale means no [reviewed] or a differing fingerprint. `stamp` writes [reviewed], keeping the rest of the card. `check_at` fails on unreviewed, stale, dead_anchor, unknown_interface (exit 1) and warns uncovered_interface, overlap, unowned, instructions_unlinked; a unit filter drops the last three. src/debt.rs `scan` lists `simplified:` comment lines of tracked non-binary files outside .stewards, keyed by unit.

## How to change it

Start from the contract row for the function you touch (route-owner, route-overlaps, route-command, anchor-resolve, anchor-source-window, anchor-interface-lines, check-fingerprint, check-stamp, check-report, check-instructions, debt-scan) and its tests: tests/route*.rs, tests/anchors.rs, tests/check.rs, tests/debt.rs. Keep ownership consistent: fingerprint, overlap and debt keys rely on `owner`. Keep the fingerprint over owned files in the snapshot, not the working tree. Keep `resolve` and `source_window` safe on bad input: a dead anchor, never a panic or a read outside the repo; instruction files go through Repo::read. To support a language, add a `grammar(...)` entry in GRAMMARS with its crate's TAGS_QUERY and, for definitions it omits, a supplement in src/anchors/ (`@definition.*` with an inner `@name`, or `@container` for a scope); a test per extension in tests/anchors.rs fails if the query does not compile. Resolving by definition means a card anchor that only names a mention goes dead, and `stewards check` fails; fix the card. `interface_lines` feeds next's interface-touched decision, so a change to which lines a span covers changes which edits schedule reviewers. If you change which findings fail or warn, update the check-report contract and exit code together; uncovered_interface stays one finding per unit. Keep the stamp merge in `reviewed_at`.

## Gaps

| kind | title | note |
|---|---|---|
| gap | debt markers can match outside comments | Any marker anywhere before \`simplified\:\` counts, so \`a \* b\` or a \`--flag\` or a \`\#\` inside a string earlier on the line reports a non-comment as debt. Line-based heuristic by design; no language-aware parsing. |
| gap | interface\_lines blocks are text heuristics | Only java kt rb php swift scala still use the text rule\: blocks come from blank lines, indent and bracket counts, so a block can end early at a blank line then a column-0 line inside a triple-quoted string, and brackets inside strings or comments count. Upgrade by adding the language's grammar to GRAMMARS. |
| gap | tags queries miss some definitions | Anchors resolve only to what a grammar's tags query or src/anchors/\*.scm captures\: TypeScript enum and type alias, Rust trait method signatures (Trait\:\:method), Go methods qualified by receiver (T.M) and quoted YAML keys are DeadName. \`.h\` parses as C, so C++ classes in headers are not definitions. Add a supplement query. |
